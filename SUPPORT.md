# Support

## Community support

`nextcloud-mcp-fast` is provided as open-source software under the
[Apache License 2.0](LICENSE), **without warranty or guaranteed response times**.

- **Questions and ideas:** [GitHub Discussions](https://github.com/valdrent/nextcloud-mcp-fast/discussions)
- **Bugs:** [open an issue](https://github.com/valdrent/nextcloud-mcp-fast/issues/new/choose)
  using the bug report template.
- **Security vulnerabilities:** never in public — follow [SECURITY.md](SECURITY.md).

When asking for help, include the version (`nextcloud-mcp-fast --healthcheck`
prints it), the transport, the permission level, and relevant logs with
credentials removed.

## Commercial support

Organizations that need support agreements, deployment assistance, or
custom features can contact Valdrent at
[support@valdrent.com](mailto:support@valdrent.com).
